# Mockup reference

Visual reference for the three screens: `Intake.dc.html`, `Main.dc.html` (compact review) and `ReviewFull.dc.html` (full review). They are inline-styled HTML with a design-tool wrapper (`x-dc`, `support.js`) that is not part of the app.

The mockups load Google Fonts for convenience only. The real app does not: it uses the self-hosted Atkinson Hyperlegible files in `public/fonts/`. The serif face in the label illustration stands in for a real label image and is not used by the app.
